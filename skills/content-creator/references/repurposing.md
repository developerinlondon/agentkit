# Repurposing one asset into a week

Read this when turning a core asset into channel-native derivatives, or when deciding what
a sustainable cadence looks like. The rule that matters most: **rewrite for the surface,
never cross-post verbatim.**

## The matrix

The core asset is the source of truth. For each derivative, the transformation is named —
so it is clear what changed and why, rather than "shorter version of the same thing".

| Derivative          | Transformation                                                               |
| ------------------- | ---------------------------------------------------------------------------- |
| **Short post**      | The single sharpest claim, standing alone without the article's context      |
| **Thread / series** | The asset's argument as sequential beats, each readable on its own           |
| **Email**           | The takeaway written to one person, with the reason to open it _now_         |
| **Visual**          | The one number, comparison, or before/after worth seeing rather than reading |
| **Snippet**         | A quotable two or three sentences plus the link, for communities and replies |

Four rules:

- **Space derivatives across the week**, rather than firing them the same day.
- **Each derivative keeps the core asset's one job.** A derivative that argues something
  else is a new asset and needs its own brief.
- **Evergreen assets re-enter the matrix after a quarter** with a fresh angle, stated
  openly as a re-run rather than disguised as new.
- **Nothing is scheduled that has not passed its voice check.**

## Cadence

Start from what can be sustained for a full quarter by the people who actually exist, then
work up. Never start from what a channel "rewards" — an abandoned channel is worse than
one never started.

Per channel record: **cadence** (posts per week) · **slot** (day, and time where it
matters) · **format** · **owner** · **purpose** (which goal it serves).

- **One core asset per week, minimum.** A week with no core asset is a week with nothing
  to repurpose.
- **Two channels done well beat five done occasionally.** Add a channel only when the
  current set has run at cadence for a month without slipping.
- **Every slot has one owner.** A slot owned by "the team" is owned by nobody.

## The weekly plan

A table at the start of each week: day · channel · asset · derived from · owner · status,
where status is drafted / scheduled / published / **slipped**.

**Slipped is a status, not a silence.** A slipped slot stays visible with its reason,
because the pattern of slips is what tells you the cadence is wrong. Three consecutive
weeks of slips on a channel is a cadence decision — cut it or shrink it — not a discipline
problem.

## Score before you plan

Open every plan with last week's scorecard: planned versus published as a count rather
than a feeling, which pieces earned unusual engagement with the honest guess at why, and
one cadence adjustment with its reason.

A team that only reports wins is reporting nothing.
