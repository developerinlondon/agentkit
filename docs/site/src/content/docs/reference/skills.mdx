A skill is a set of instructions the agent loads when the work matches it. Unlike a hook, a skill
cannot refuse anything — it makes the work better when it is loaded and changes nothing when it is
not. Reach for a skill when the failure is "the output was worse than it should have been", and for
a hook when the failure is "that should not have been allowed".

This catalogue is generated from `skills/` and `skills/KITS` at build time. The descriptions are
the skills' own frontmatter, which is also what the agent sees when deciding whether to load one.

## Kits

A kit decides whether a skill is installed. Anything with no kit record belongs to `core`,
which always installs.

<KitTable />

:::caution[An explicit kit is consent-gated in both directions]
An explicit kit is never offered by the interactive picker and is excluded from `--all`. It
installs only when you name it: `--with adversarial-review`. If it is not named on a later install run,
the installer **removes** the artifacts it previously installed — presence without a recorded
selection is not treated as consent.
:::
