# Brand

| File                    | Use                                                  |
| ----------------------- | ---------------------------------------------------- |
| `agentkit-logo-512.png` | source-resolution square mark                        |
| `agentkit-logo-120.png` | Google OAuth consent screen (120x120 is the minimum) |

The mark is the prompt chevron and cursor bar from `docs/site/public/favicon.svg`,
redrawn at icon scale. Palette: `#f5a742` on `#08090a`.

Google's consent screen takes a square JPG/PNG/BMP of at least 120x120 and under 1 MB.
Uploading one moves the project into Google's brand-verification queue, so an app that
only needs `openid`/`email`/`profile` can ship without ever setting it.
