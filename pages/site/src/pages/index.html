Rules that hold even when the prompt doesn't

Instructions drift, context windows truncate, and models forget. Police hooks don't — they sit at the tool boundary and evaluate every command deterministically. Every refusal above is the text a hook actually prints.

The same policies compile to each harness's native mechanism: Claude Code hooks, OpenCode plugins, Codex exec policies, Grok rules. One source tree, four enforcement surfaces.
